Lead Finder Agent - Project Analysis

1. Project Overview

Lead Finder Agent is a full-stack lead generation and business intelligence platform that automatically discovers, analyzes, and enriches business leads from Google Maps and business directories.

Purpose: Automate the lead generation process by scraping business directories, analyzing websites for contact information, and providing AI-powered insights about business potential and outreach strategies.

7. Authentication & Security

Authentication Flow

  • User logs in with email/password
  • JWT access token (15 min expiry) + refresh token (7 day expiry) issued
  • Tokens stored in localStorage/sessionStorage (based on "remember me" option)
  • Automatic token refresh on 401 errors
  • Role-based access control (Admin, User)

Security Features

  • JWT authentication
  • Password hashing (bcrypt)
  • Fernet encryption for sensitive API keys
  • CORS configuration (environment-controlled origins)
  • Rate limiting (slowapi)
  • Security headers middleware
  • Request size limits (10MB max)

8. AI Analysis Pipeline

Workflow State Machine

PENDING → RUNNING → COLLECTING → ANALYZING → SCORING → SAVING → SUCCESS
                                              ↘ FAILED (on error)
  • Collection Stage: Crawl website, discover pages, extract contacts
  • Analysis Stage: SEO analysis, performance metrics, design audit
  • Scoring Stage: Calculate business intelligence scores
  • Saving Stage: Persist results to MongoDB

AI Providers

  • OpenAI Provider: Primary AI provider (GPT models)
  • Provider Factory: Dynamic provider selection based on configuration

9. Frontend Architecture

State Management

  • React Query: Server state management with auto-caching

7. Configure NGINX Reverse Proxy

sudo nano /etc/nginx/sites-available/lead-finder
upstream frontend { server 127.0.0.1:3000; }
upstream backend { server 127.0.0.1:8000; }

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    
    location / {
        proxy_pass http://frontend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }

    location /api/v1/ {
        proxy_pass http://backend/api/v1/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_read_timeout 86400; # For WebSockets
    }
}

Enable and start NGINX:

sudo ln -s /etc/nginx/sites-available/lead-finder /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
